## About This Portfolio

This repository documents a practitioner-grade GRC and cloud 
security portfolio built across the following domains:

- ISO 27001 ISMS design and audit preparation
- NIST CSF 2.0 programme assessment and remediation roadmap design
- IAM governance — identity lifecycle, NHI governance, PAM, SoD
- Data Loss Prevention policy architecture
- Third-party risk assessment and vendor governance
- Cloud security architecture — Azure and AWS
- Vulnerability management governance
- AI governance aligned to ISO 42001 and the EU AI Act

The methodology applied throughout reflects Fortune 500 GRC practice standards: frameworks referenced include NIST CSF 2.0, ISO 27001:2022, NIST SP 800-53, NIST SP 800-161r1, and regulatory requirements drawn from HIPAA, GDPR, GLBA, SOX, NYDFS 23 NYCRR 500, and Nigeria's NDPA.
